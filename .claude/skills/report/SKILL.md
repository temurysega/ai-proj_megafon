# Навык: проверка качества и отчёт

1. `strategy/one-pager.md` по шаблону `knowledge/templates/one-pager.md` — читается за 2 минуты; решение,
   3 основания `[C…]`, отвергнутые варианты, 3 риска, что проверить за 2 недели, чего не знаем, стоимость/время.
2. Ворота качества — `knowledge/checklists/quality-gate.md`:
   - `python sf.py check --strict` → 0 ошибок (сверка каждой цитаты со снимком, результаты стадии, числа без ссылок — ошибки);
   - субагент `fact-checker` по 15–20 ключевым утверждениям; исправь расхождения;
   - субагент `red-team` по стратегии: согласованность продукта и коммуникаций, обещания ↔ продукт;
   - (опционально) субагент `jury` или `python sf.py eval judge` — оценка по рубрике `evals/rubric.yaml`.
3. `python sf.py render --pdf` → `report/index.html` и `report/index.pdf`.
4. Покажи человеку one-pager и ссылку на отчёт; попроси принять или поправить (ворота G3).
5. Принято → `python sf.py gate G3 pass --note "..."` → `python sf.py stage support` → навык `decision-support`.
