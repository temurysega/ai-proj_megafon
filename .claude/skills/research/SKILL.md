# Навык: исследование

1. Прочитай `knowledge/methods/decision-questions.md` и `evidence-grading.md`.
2. `research/plan.md` по шаблону `knowledge/templates/research-plan.md`: 4–7 решающих вопросов DQ, для каждого —
   какой ответ к какому варианту ведёт, чем отвечаем, приоритет. Вопросы без влияния на решение — в «не исследуем».
3. Отвечай на DQ по приоритету:
   - кабинетные источники → `fetch` → утверждения `claim add` с цитатами и тегом DQ;
   - параллельно — субагенты `researcher` (по одному DQ на субагента);
   - интервью/модельные респонденты → навык `interviews`; интерфейсы → `ux-review`; данные → `data-analysis`.
4. Сопоставляй: ключевые цифры — два независимых источника; противоречие → оба утверждения `disputed` + разбор.
5. Расчёты — утверждения `estimate` с `--depends` и `--method` (скрипт в `research/data/`).
6. `research/findings.md` по шаблону: коротко → известно (по DQ) → предполагаем → **чего не знаем** (почему,
   влияние, как узнать) → противоречия. Каждое предложение с фактом — со ссылкой `[C…]`.
7. Проверка фактов: субагент `fact-checker` по ключевым утверждениям (сверка цитат со снимками). Расхождения исправь.
8. `python sf.py check` → 0 ошибок. Чекпойнт. Переход: `python sf.py stage options`.

Достаточность: исследование закончено, когда на каждый DQ есть ответ или явно названный пробел — а не когда
«всё изучено». Бюджет времени/денег важнее полноты.
