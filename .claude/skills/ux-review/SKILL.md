# Навык: анализ UX

1. Прочитай `knowledge/methods/ux-heuristics.md`.
2. Скриншоты: `python sf.py capture <url> --name <имя>` (desktop) и `--mobile`. Собственные скриншоты:
   `python sf.py ingest <png> --public-media --describe` для открытого скриншота без ПДн. При захвате страницы видимый текст сохраняется рядом (`.txt`) — опора для цитат.
3. Разбор: субагент `ux-analyst` (или ты сам — прочитай PNG) по чек-листу: ценность за 5 секунд, цена и условия,
   следующий шаг, доверие, язык аудитории, нагрузка, доступность для пожилых.
4. Каждый вывод: `[S0xx] где на экране → что видно (дословный текст)` → вывод. Если элемента нет на скриншоте —
   «не видно на скриншоте», а не «нет в продукте».
5. `research/ux/review.md`: таблица сравнения + главные разрывы пути «узнал → понял → поверил → подключил → польза».
6. Существенные выводы → утверждения (`fact` о видимом содержимом со ссылкой на скриншот-источник; оценки — `hypothesis`).
