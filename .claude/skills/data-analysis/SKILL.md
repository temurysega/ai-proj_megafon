# Навык: анализ данных

1. Прочитай `knowledge/methods/data-quality.md` (и `retention-diagnostics.md`, если вопрос про удержание).
2. Зарегистрируй набор: `python sf.py ingest <файл>` (или сохрани открытую статистику в `research/data/*.csv` с
   источником в шапке/реестре).
3. Профиль: `python sf.py data profile <файл>` → разбери каждое замечание (единицы, периоды, пропуски, смена методики).
4. Анализ — скриптом `research/data/<имя>.py` с шапкой `# inputs: ...` и `# outputs: ...`; запуск
   `python sf.py data run research/data/<имя>.py` фиксирует хэши входов/выходов (воспроизводимость).
5. Каждый результат → `claim add --kind estimate --depends <C…входы> --method research/data/<имя>.py`.
6. Графики (если нужны) — PNG в `research/data/`, подпись: показатель, единица, период, источник.
7. Не делай причинных выводов из корреляций; для «почему» — гипотезы и план проверки.
