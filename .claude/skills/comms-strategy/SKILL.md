# Навык: коммуникационная стратегия

1. Прочитай `knowledge/methods/messaging.md` и `legal-comms-ru.md`.
2. `strategy/communication.md` по шаблону `knowledge/templates/communication-strategy.md`. Обязательные разделы:
   аудитория и ситуация · барьер · ключевое сообщение · подтверждение · роль каналов · обещания ↔ продукт.
3. Барьер — из исследования (интервью, отзывы, данные) со ссылкой `[C…]`; синтетика допустима только как
   гипотеза барьера, с пометкой и проверкой в плане.
4. Ключевое сообщение — одна фраза, снимающая главный барьер; подтверждения — проверяемые факты о продукте.
5. Каналы — по задачам (охват/объяснение/конверсия/удержание) с метрикой.
6. Таблица «обещания ↔ продукт»: каждое обещание — на свойство из `product.md`; без свойства — удалить.
7. «Чего не говорим»: абсолютные гарантии, запугивание уязвимых, некорректные сравнения.
8. Проверка формулировок (по желанию): модельные респонденты-скептики (`sf respondents`) — только на понятность.
