# Навык: сопровождение решения

1. Прочитай `knowledge/methods/decision-support.md`.
2. `decisions.yaml` по шаблону `knowledge/templates/decisions.yaml`: основания `rationale_claims` (утверждения),
   допущения, владельцы-роли, метрики (база/цель/дата), обязательства (что/кто/срок), триггеры пересмотра
   (дата; статус ключевого утверждения; порог метрики — kill criteria).
3. `python sf.py decisions check` → без ошибок.
4. Регулярно (и при каждом старте сессии в стадии support): `python sf.py decisions due` → покажи человеку,
   что решать сейчас: просрочки, сработавшие триггеры, старые допущения.
5. Новое значение метрики от человека: `python sf.py decisions observe --decision D1 --metric "<имя>" --value <x>`.
6. Обязательство выполнено: `python sf.py decisions commitment --decision D1 --commitment K1 --status done`.
7. Сработал триггер → навык `revisit`; итог пересмотра записывай в решение (`status: under_review` → `active`/`reversed`).
