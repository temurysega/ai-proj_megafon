# Навык: постановка задачи

1. Создай проект: `python sf.py new <id-латиницей> --title "<коротко>" --request "<запрос дословно>"`.
2. Если приложены материалы — сначала зарегистрируй и прочитай их (`python sf.py ingest <файл>`), не спрашивай то, что в них есть.
3. Прочитай `knowledge/methods/intake-questions.md`. Заполни `brief.md` по `knowledge/templates/brief.md`
   всем, что известно. Для неизвестного — разумное допущение: `python sf.py claim add --kind assumption --text "..."`
   и ссылка `[C…]` в разделе «Допущения».
4. Сформулируй «Решаемый вопрос» как выбор между вариантами (это основа плана исследования).
5. Вопросы человеку — только влияющие на следующий шаг, максимум 3, каждый с «зачем» и значением по умолчанию:
   `python sf.py ask add --text "..." --why "..." --default "..."`. Покажи их одним сообщением.
6. Чек-лист: `knowledge/checklists/intake.md`.
7. Покажи бриф кратко (5–8 строк) и попроси подтвердить или поправить. `python sf.py checkpoint "бриф готов" --next "получить подтверждение брифа (G1)" --waiting`.
8. Ответ человека → `python sf.py ask answer Q1 --text "..."`, поправь бриф; подтверждение → `python sf.py gate G1 pass --note "<что подтвердил>"`
   → `python sf.py stage materials`.

Режим autopilot: не задавай вопросов, прими значения по умолчанию, `gate G1 assume`.
