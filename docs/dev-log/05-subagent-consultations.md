# 05. Журнал консультаций с субагентами (Sonnet / Haiku) и что они изменили

Все вызовы — через инструмент Agent в Claude Code. Токены — из отчёта о завершении субагента; стоимость — по ценам API
(Sonnet ≈ $6, Haiku ≈ $2 за 1 млн токенов смешанно), записана командой `sf cost --add … --kind subagent`.

|---|---|---|---|---|---|---|
| 1 | 14.11 | жюри-архитектор | Sonnet | 58 609 | оценить проект архитектуры по 4 критериям | 10 решений (`02-sonnet-architecture-review.md`): шаблоны с обязательными разделами, режим без ключа, изоляция чтения, политика данных |
| 2–6 | 14.11 | researcher ×5 | Sonnet | 350 тыс. | DQ1–DQ5: конкуренты, динамика, регулирование, аудитория, эффект и партнёры | 37 утверждений; импорт со сверкой цитат поймал 403-страницу и искажение «не платят» → «не готовы платить» |
| 7–11 | 14.11 | respondent ×5 | Haiku | 289 тыс. | 5 персон по гайду (режим без ключа OpenRouter) | 5 синтетических интервью (`research/interviews/synthetic/`) |

| 20 | 15.11 | jury | Haiku | 71 тыс. | то же, обратный порядок | агент 8,8 / чат 5,1; найдено несведённое противоречие 149/249 ₽ → C077 |

**Итого:** 23 вызова (с учётом пяти исследователей и пяти респондентов), ≈1,6 млн токенов субагентов, ≈$6,8.

**Наблюдения о пользе:** дешёвый Haiku-факт-чекер окупился сильнее всего — 10 исправлений на ≈$0,6; красная команда Sonnet нашла две
ошибки, которые изменили содержание рекомендации (модель экономики, дизайн эксперимента); жюри из двух моделей дало согласованные оценки
(разница ≤1 балла по каждому критерию) и два практических улучшения.
