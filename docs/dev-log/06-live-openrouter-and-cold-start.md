## 2. Ошибки, найденные живым прогоном, и исправления
1. **Qwen 3.7 flash возвращал пустой ответ** на классификации: модель по умолчанию «рассуждает» и тратит весь лимит
   (`finish_reason=length`, рассуждение 1 616 символов, ответ пустой). Исправление: в `config/routing.yaml` у каждой задачи параметр
   `reasoning` (`off` для массовых операций, `low` для судьи и критика); пустой ответ теперь отдельная ошибка с эскалацией.
   Эффект: классификация подешевела в 12 раз ($0,000035 → $0,000003) и перестала падать.
2. **В тексте ошибки OpenRouter приходит идентификатор аккаунта** (`user_…`), и он попал в журнал проекта. Журналы вычищены до
   коммита (в истории git его нет — проверено), ошибки теперь очищаются в `llm.py` до записи.
3. **Телефон, продиктованный словами** («плюс семь девятьсот двенадцать…»), не вычищался из расшифровки аудио. Добавлен шаблон для
   числительных, регрессионный тест; расшифровка S045 очищена повторно.
4. **Управляющие символы в регулярных выражениях** (`\b` превращался в символ backspace при генерации кода): проверка «фактических
   строк» и шаблон телефонов работали не так, как задумано. Исправлено; добавлена проверка в отчёте.

добавится загрузка пакетов и Chromium (≈1–3 мин в зависимости от сети).
