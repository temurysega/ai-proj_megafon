# Сквозная демонстрация по брифу организаторов

[MP4](family-connect.mp4) · [Субтитры WebVTT](family-connect.vtt) · [Стратегия](../../projects/family-connect/strategy/document.md) · [Отчёт PDF](../../projects/family-connect/report/index.pdf)

Продолжительность 3:57, 1280×720. Русские субтитры встроены, запись без звуковой дорожки.

| Время | Что в кадре |
|---|---|
| 00:00 | Запрос руководителя, два уточнения, подтверждение G1 |
| 00:29 | Оригинал PDF как S001 и цитата из брифа |
| 00:42 | Факты, допущения, пробел и повтор расчёта |
| 01:13 | Шесть вариантов и возражения |
| 01:31 | Возобновление в новом процессе по чекпойнту G2 |
| 02:14 | Стратегия из пяти частей, продукт и сообщение, пилот и экономика |
| 03:00 | Цена закрытия годовых разрывов и проверка полного кабинета |
| 03:15 | Строгая проверка |
| 03:27 | Приёмка G3, обязательства, зависимости и следующий шаг |

Запрос, варианты и ответы руководителя взяты из артефактов исходной сессии. По стратегии показана актуальная редакция с пересчитанной экономикой. На кадрах с пометкой «Новый запуск» показаны фактические результаты свежих запусков. Чтобы воспроизвести продолжение, скрипт извлекает архивный проект в ожидании G2 из коммита `7fb6003` во временную папку, запускает `sf status` и хук `SessionStart` в отдельных процессах, затем прикладывает сохранённый текст выбора B и проверяет переход к стратегии. Строгая проверка и команды сопровождения работают на временной копии готового проекта.

Для пересборки нужна история Git с коммитами проекта. Из корня репозитория выполните:

```bash
python -m pip install -r requirements.txt
python -m pip install imageio-ffmpeg
python -m playwright install chromium
python scripts/record_family_connect.py
```
