Запрос, варианты и ответы руководителя взяты из артефактов исходной сессии. По стратегии показана актуальная редакция с пересчитанной экономикой. На кадрах с пометкой «Новый запуск» показаны фактические результаты свежих запусков. Чтобы воспроизвести продолжение, скрипт извлекает архивный проект в ожидании G2 из коммита `7fb6003` во временную папку, запускает `sf status` и хук `SessionStart` в отдельных процессах, затем прикладывает сохранённый текст выбора B и проверяет переход к стратегии. Строгая проверка и команды сопровождения работают на временной копии готового проекта.

## Пересборка видеоряда

Из Git-клона с историей можно пересобрать исходный видеоряд без звука в `.cache/family-connect-silent`. Готовый ролик с озвучкой доступен по ссылке выше.

```bash
python -m pip install -r requirements.txt
python -m pip install imageio-ffmpeg
python -m playwright install chromium
python scripts/record_family_connect.py
```
