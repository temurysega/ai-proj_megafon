## Дополнительно для Claude Code
- Навыки (`.claude/skills/`) подгружаются автоматически по описанию; если не подгрузился — прочитай `SKILL.md` нужной стадии.
- Субагенты (`.claude/agents/`): запускай `researcher` параллельно по разным решающим вопросам; `fact-checker`
  и `red-team` — перед показом вариантов и стратегии. После каждого субагента запиши его токены:
  `python sf.py cost --add <usd> --kind subagent --tokens <n> --stage <стадия> --model <модель> --note "<субагент>"`
  (оценка: sonnet ≈ $6 за 1 млн токенов смешанно, haiku ≈ $2).
- Хуки (`.claude/settings.json`) сами: подают статус при старте, защищают правила и секреты, проверяют ссылки
  после записи документов, учитывают токены сессии и напоминают сделать чекпойнт.
- Команды: `/new`, `/resume`, `/status`, `/pause`, `/decide`, `/revisit`, `/report`, `/check`.
