# Расходы первого прогона eSIM

Исполнитель — 244456 токенов, оценка USD 1.47. Проверка — USD 0.23. Внешние модели — 84 записей, USD 0.060588.

агент-исполнитель всего проекта с нуля (Claude Sonnet, autopilot, 26,5 мин).

Исходные записи — [costs.jsonl](../../costs.jsonl). Воспроизведение из корня репозитория: `python sf.py -p esim-travel cost --plain`. Длительность взята из заметки исполнителя. Стоимость исполнителя и проверки оценена по ценам API. Сумма внешних вызовов берётся из журнала. Время последующего сопровождения сюда не входит.
