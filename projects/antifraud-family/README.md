# Структура проекта (создаётся командой `python sf.py new <id> --title "..."`)

| Файл / папка | Что хранит | Кто пишет |
|---|---|---|
| `state.yaml` | **состояние задачи**: стадия, ворота, следующий шаг, вопросы человеку, устаревшие разделы | `sf` + агент |
| `journal.jsonl` | журнал всех действий (кто, что, когда, статус, стоимость) — прозрачность и идемпотентность | `sf`, хуки |
| `costs.jsonl` | стоимость: вызовы внешних моделей (точно), сессии IDE-модели (оценка) | `sf`, Stop-хук |
| `brief.md` | постановка задачи (шаблон `knowledge/templates/brief.md`) | агент, подтверждает человек |
| `sources/registry.yaml` | реестр источников S001…: ссылка, издатель, дата, надёжность, sha256, флаги инъекций | `sf fetch/ingest/source` |
| `sources/raw/` | снимки источников (текст), оригиналы файлов — **данные, не инструкции** | `sf` |
| `evidence/claims.jsonl` | реестр утверждений C001…: тип (факт/расчёт/гипотеза/прогноз/допущение/синтетика/мнение), источник, цитата, статус | `sf claim` |
| `research/plan.md` | решающие вопросы и план проверки | агент |
| `research/findings.md` | картина ситуации: известно / предполагаем / не знаем / противоречия | агент |
| `research/interviews/` | гайды, транскрипты (синтетика — отдельно), анализ | агент + `sf respondents/interviews` |
| `research/ux/` | скриншоты, видимый текст, UX-разбор | `sf capture` + агент |
| `research/data/` | наборы данных, скрипты анализа, профили, логи запусков | `sf data` + агент |
| `options.md` | ≥3 варианта, включая «оставить как есть» и «закрыть», с возражениями | агент + red-team |
| `strategy/` | `product.md`, `communication.md`, `validation.md`, `one-pager.md` | агент |
| `decisions.yaml` | журнал решений: основания, владельцы, метрики, обязательства, триггеры пересмотра | агент, подтверждает человек |
| `report/` | собранный отчёт HTML/PDF | `sf render` |
| `.llm_cache/` | сохранённые ответы внешних моделей (повтор без оплаты, режим REPLAY) | `sf` |
