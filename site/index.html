Проверяемость

Каждое слово — с источником.

Факт нельзя записать без источника и дословной цитаты. Ссылки проверяются сразу при записи и ещё раз перед показом человеку.

S014Источник

Снимок страницы с отпечатком sha256 и проверкой на инструкции для ИИ.

Тип, дословная цитата, место в документе, статус.

[C023]Стратегия

Метка в тексте. Наведите или нажмите — увидите основание.

Пауза и продолжение

Остановитесь когда угодно.
Продолжите в новом чате.

Состояние задачи живёт в файлах проекта, а не в истории переписки. Подойдёт и другая среда разработки.

  1. 1Вы пишете «стоп». Агент завершает текущий шаг и сохраняет точку с конкретным следующим действием.
  2. 2Новый чат, одно слово: «продолжай».
  3. 3Агент сразу получает состояние: стадию, решения, открытые вопросы, сроки.
  4. 4Ничего не переспрашивает и не повторяет уже сделанное.

Условия пересмотра

Дата вступления закона, изменение ключевого основания, порог метрики. Когда условие срабатывает, агент сам поднимает решение на пересмотр.

Честное правило решения

Решение по доверительному интервалу эффекта. «Незначимо» не значит «эффекта нет».

Три команды. И ваша задача.

Python 3.10+ и среда с агентом: Claude Code, Cursor, Codex или Copilot.

pip install -r requirements.txt
python -m playwright install chromium
python sf.py doctor --install-git-hook

Затем откройте папку в среде с агентом и напишите задачу своими словами.
