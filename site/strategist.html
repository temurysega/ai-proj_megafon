Путь 3

Пауза и продолжение в новом чате

Состояние задачи живёт в файлах проекта, а не в истории переписки. Поэтому продолжить можно в новом чате или в другой среде.

  1. 1Человек пишет «стоп». Агент завершает текущий шаг и сохраняет чекпойнт с конкретным следующим действием.
  2. 2Новый чат, одно слово: «продолжай».
  3. 3Хук при старте сам подаёт состояние: стадию, ворота, открытые вопросы, сроки обязательств.
  4. 4Агент не переспрашивает бриф и не повторяет исследование. Выполненные шаги не оплачиваются второй раз.

На демо так и было: сессия оборвалась на вопросе о выборе варианта, и в новом чате агент сразу задал его снова.

Триггеры пересмотра

Дата (вступление закона 01.03.2027), смена статуса ключевого основания (например, конкурент изменил условия), порог метрики (доля согласий близких ниже 40% — остановка).

Правило решения

Решение о бесплатной базе — по нижней границе доверительного интервала эффекта. «Незначимо» не трактуется как «эффекта нет».

Кто что делает

Сильная модель думает, узкие задачи — специалистам

Основная модель IDE

Постановка, синтез, варианты, стратегия — там, где цена ошибки выше. Читает правила из AGENTS.md и навыки стадий.

Субагенты

Исследователи по одному решающему вопросу, проверка фактов, красная команда, разбор интерфейсов, модельные респонденты, жюри. Читающие не могут писать в проект.

Запуск

Три команды и задача агенту

Python 3.10+ и среда с агентом: Claude Code, Cursor, Codex или Copilot. Ключ OpenRouter не обязателен.

pip install -r requirements.txt
python -m playwright install chromium
python sf.py doctor --install-git-hook

Затем откройте папку в среде с агентом и напишите задачу своими словами. Продолжить после перерыва — «продолжай» в новом чате.
