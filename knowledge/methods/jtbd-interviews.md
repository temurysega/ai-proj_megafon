# Интервью (Jobs To Be Done)

## Принципы гайда
- Спрашивать о **прошлом поведении**, а не о будущем намерении («Расскажите о последнем случае, когда…»,
  а не «Купили бы вы…?»).
- Не называть своё решение до конца интервью; не спрашивать «нравится ли идея».
- Открытые вопросы; уточнения «почему», «что было дальше», «что вы сделали»; паузы.
- Структура: контекст → последний случай (таймлайн: первая мысль → поиск → выбор → использование) →
  альтернативы → барьеры и тревоги → критерии выбора → цена (как сейчас платят за похожее).

## Анализ
- Кодирование: задачи (jobs), боли, текущие решения, барьеры, триггеры, слова аудитории (дословно).
- Частоты «n из N интервью» — только для реальных интервью; это не доля рынка.
- Цитаты — дословные (агент проверяет дословность автоматически, выдуманные отбрасываются).
- Результат → утверждения типа `hypothesis` (реальные интервью — `fact` о том, что *сказал респондент*,
  но не о распространённости).

## Выборка
5–8 интервью на сегмент обычно дают повторяющиеся темы (насыщение); для количественных выводов нужен опрос.
