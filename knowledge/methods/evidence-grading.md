# Доказательная база

## Типы утверждений (поле `kind` в `evidence/claims.jsonl`)
| Тип | Определение | Требование |
|---|---|---|
| **факт** (`fact`) | Наблюдаемое/опубликованное сведение | источник + дословная цитата или локатор (стр., раздел, таблица) |
| **расчёт** (`estimate`) | Вычислено из фактов | входные утверждения (`--depends`) + метод/скрипт (`--method`) |
| **мнение** (`opinion`) | Оценка эксперта/СМИ/компании о себе | источник; в стратегии подавать как мнение |
| **гипотеза** (`hypothesis`) | Правдоподобное, но не проверенное | как проверить — в плане проверки |
| **прогноз** (`forecast`) | Утверждение о будущем | на чём основан, горизонт, диапазон |
| **допущение** (`assumption`) | Принято для расчёта без проверки | кто принял и почему; срок пересмотра |
| **синтетика** (`synthetic`) | Из модельных интервью | не доказывает спрос, долю, распространённость |

Пресс-релиз компании о собственном продукте — это **мнение компании** или факт о том, *что компания
заявила*, а не независимое подтверждение эффективности.

## Надёжность источника (A–D)
- **A** — первичный/официальный: регулятор, закон, отчёт компании, публичная оферта, сама страница продукта.
- **B** — авторитетный вторичный: деловые СМИ, отраслевые аналитики с описанной методикой.
- **C** — вторичный: агрегаторы, блоги, перепечатки, рейтинги без методики.
- **D** — непроверенный, синтетика.

## Правила
1. **Существенная цифра — минимум из одного A/B-источника**; если только C — пометить уверенность `low`.
2. **Триангуляция**: ключевые для решения факты подтверждать двумя независимыми источниками.
   Перепечатка одной новости в пяти СМИ — это один источник.
3. **Противоречия не сглаживать**: записать оба утверждения, статус `disputed`, объяснить причину
   (разная методика, период, база) в `findings.md → Противоречия`.
4. **Даты и периоды**: у каждой цифры — период и дата публикации; не смешивать 2024 и 2026.
5. **Единицы**: «млрд руб.», «тыс. операций», «% от …» — всегда с базой процента.
6. **Не превращать ответ агента в факт**: выводы агента — гипотезы, пока не подтверждены источником.
7. **Синтетика**: никогда не используется как довод о спросе/доле (`sf check` это ловит).

## Уверенность (`confidence`)
`high` — A-источник или два независимых B; `medium` — один B; `low` — C, косвенные данные, экстраполяция.
