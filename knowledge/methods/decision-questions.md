# Решающие вопросы (decision-relevant questions)

## Идея
Исследование строится не «про тему», а от вопросов, **ответ на которые может изменить решение**.
Если любой ответ ведёт к тому же решению — вопрос не исследуем (экономия времени и денег).

## Как сформулировать
1. Запишите решение, которое предстоит принять (например: «оставить платную подписку / сделать бесплатной / закрыть»).
2. Для каждого правдоподобного варианта спросите: **что должно быть правдой**, чтобы он оказался лучшим? (Roger Martin)
3. Каждое такое условие превратите в вопрос DQ: «Готовы ли семьи платить отдельно за X при бесплатной базе у конкурентов?»
4. Для каждого DQ запишите: какой ответ склонит к какому варианту (если ответ ничего не меняет — вычеркните).

## Приоритизация (ценность информации)
| Фактор | Вопрос |
|---|---|
| Влияние | Насколько сильно ответ меняет выбор/экономику? |
| Неопределённость | Насколько мы сейчас не уверены? (уверены → не исследуем) |
| Стоимость ответа | Сколько стоит получить ответ (поиск, данные, интервью, тест)? |
| Обратимость | Если решение легко отменить — лучше быстро проверить в рынке, чем долго исследовать |

Приоритет ≈ влияние × неопределённость / стоимость. Необратимые решения (закрытие, крупные вложения)
заслуживают более глубокой проверки.

## Чем отвечать
- **Кабинетное исследование** (открытые источники) — рынок, конкуренты, регулирование, статистика.
- **Данные продукта** (если есть) — поведение, когорты, воронки → [[data-quality]], [[retention-diagnostics]].
- **Интервью** — мотивы, барьеры, слова аудитории → [[jtbd-interviews]]. Модельные респонденты — только для гипотез → [[synthetic-respondents]].
- **Анализ интерфейсов** — что видит пользователь → [[ux-heuristics]].
- **Рыночный тест** — когда остальное не даёт ответа → [[validation-design]].

## Честные пробелы
Если ответа нет в доступных источниках — так и пишем в `findings.md → Чего не знаем`:
*что именно неизвестно, почему (нет открытых данных / закрытые данные компании / противоречие источников),
как это влияет на решение и как это можно узнать (кто, чем, сколько стоит)*.
