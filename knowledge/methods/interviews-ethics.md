# Этика реальных интервью

1. **Согласие** до записи: цель, кто увидит материалы, право отказаться. В шапке транскрипта:
   `consent: yes`, дата, способ получения согласия (без ФИО). Без этой строки агент не обрабатывает файл.
2. **Обезличивание** до сохранения в репозиторий и до отправки любой модели: имена, телефоны, email,
   адреса, номера документов/карт заменяются метками (`safety.scrub_pii`), респонденты — кодами R01…
3. **Аудиозаписи** не хранятся в репозитории (`.gitignore`), только обезличенные расшифровки.
4. **Минимизация**: собирать только данные, нужные для решения.
5. **Уязвимые группы** (пожилые, дети): присутствие доверенного лица по желанию респондента, простой язык.
