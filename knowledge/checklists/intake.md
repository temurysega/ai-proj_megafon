# Чек-лист постановки (перед воротами G1)
- [ ] Решаемый вопрос сформулирован как выбор между вариантами
- [ ] Цель и критерий успеха названы (или записаны допущением)
- [ ] Получатель и формат результата понятны
- [ ] Ограничения перечислены (включая «только открытые данные»)
- [ ] Приложенные материалы прочитаны и зарегистрированы как источники
- [ ] Вопросов человеку ≤ 3, у каждого — «зачем» и значение по умолчанию
