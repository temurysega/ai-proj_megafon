# Учебная сводка цифрового каталога

Сценарий вымышлен. Выгрузка условно содержит первую поисковую сессию каждого из 500 посетителей за четыре недели. В 300 сессиях было хотя бы одно парное событие показа доступного экземпляра, в 200 такого события не было. Резерв подтвердили 90 посетителей первой группы и 10 второй. Эти записи не устанавливают, действительно ли остальные экземпляры были недоступны. Статус сейчас виден только на странице экземпляра. На странице также показаны пункт выдачи и дата последнего обновления. Маржа на резерв отсутствует. Цель библиотеки — упростить подтверждённый резерв без роста ошибочных визитов, с сохранением доступа к полному каталогу.
