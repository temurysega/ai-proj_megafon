## Повторить проверку результатов

В новом клоне после установки зависимостей выполните из корня репозитория:

```text
python sf.py import evals/cold_start/ceramics-audit.zip
python sf.py -p ceramics-audit check --strict
python sf.py -p ceramics-audit data run research/data/no_show.py
python sf.py -p ceramics-audit decisions check
python sf.py -p ceramics-audit status
python sf.py -p ceramics-audit decisions due
```

## Повторить работу модели с нуля

Откройте чистый клон в IDE, отправьте цитированный запрос и приложите `evals/cold_start/studio-brief.md`. Укажите использовать только сводку и пройти этапы в `autopilot`, записав допущения. Для проверки остановки и продолжения можно на этапе вариантов написать «стоп», открыть новый чат и написать «продолжай». Оценочные формулировки могут меняться между запусками. Доли из сводки и ссылки на её строки можно проверить независимо.
