# Рубрика до получения ответов

Учебный кейс `brief.md`. Восемь проверок по одному баллу. Балл получает любой ответ, в котором есть все условия указанной строки. Допускаются корректное округление и эквивалентная формулировка. Предпочтения в стиле и объём текста оценку не меняют.

| № | Проверка | Условие зачёта |
|---|---|---|
| 1 | Сверка событий | Вычтены повторы в обеих ветках. Указаны уникальные продления по всем сегментам: 327/360, 256/258, 178/175 (контроль/тест) |
| 2 | Эффект на исходной базе | Эффекты +5,5 / +0,5 / −1,2 п.п. с делением на всех назначенных и ссылкой на S02–S03 |
| 3 | Экономика вариантов | Для текущего процесса 0 ₽, для всех −25 800 ₽, для малых +65 200 ₽. Учтены дополнительные обращения, стоимость рассылки и однократная фиксированная сумма |
| 4 | Чувствительность | Окупаемость малых при приросте ≈3,24 п.п. и результат при половине наблюдаемого эффекта −14 000 ₽ |
| 5 | Безопасность | Разницы по жалобам +0,5 / +2,5 / +0,4 п.п. Средний сегмент исключён по правилу S04 |
| 6 | Действие и проверка | Сохраняется текущий процесс вне теста на малых. Есть случайный контроль, окно 30 дней и правило выхода на полную отправку: подтверждение эффекта выше порога окупаемости и соблюдение лимита жалоб |
| 7 | Коммуникация | Текст напоминания содержит дату, сумму и действие через настройки. Нет обещания гарантированного получения, чтения или успешного платежа |
| 8 | Передача решения | Явно указан статус прежнего решения об отправке всем, причина пересмотра со ссылкой на S03, ответственный за следующее решение и момент пересмотра |

Воспроизводимость проверяется отдельно от восьми баллов. Для чисел засчитывается опубликованный расчёт, если новый проверяющий получает заявленные результаты. Для сопровождения фиксируется, можно ли восстановить состояние, основание решения и следующий шаг из файла проекта в новом процессе. Ручное текстовое резюме засчитывается в пункте 8 независимо от наличия файла проекта. Допускается приводить точные совпадения и расходящиеся результаты. Для сравнения используются одна модель, одинаковый бриф и запрос. Внешний поиск исключён.
